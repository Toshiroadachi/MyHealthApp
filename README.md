# MyHealthApp

## 🏋️ 筋トレ記録アプリ（`index.html`）
公開URL: https://toshiroadachi.github.io/MyHealthApp/

スマホでタップするだけで筋トレ・有酸素運動を記録できるWebアプリです。データはスマホの中（ブラウザ）に保存されます。

### 機能
- **タップで記録**: メニューをタップ → ＋/− やワンタップ候補で入力（前回の値が自動で入ります）
  - 筋トレ: 重量・回数・セット数
  - 水泳・自転車: 距離・時間（水泳は m、自転車は km）
  - トレッドミル: 速度・距離・傾斜
- **メニュー管理**: 「✏️ 編集」から追加・名前変更・削除・並び替え・記録の種類の変更
- **部位**: 大胸筋・上腕二頭筋などの細かい部位を、1メニューにつき最大3つ（最初が「主」）。部位の追加・名前変更・大分類・色の変更も可能
- **履歴**: カレンダーと日別一覧（大分類で絞り込み）
- **部位マップ**: 人体図（前面・背面）で、1週間・1ヶ月・全期間にどの部位をどれだけ鍛えたかを割合で表示
- **グラフ**: 期間 × 指標（セット数・総回数・ボリューム・距離・時間）× 大分類／筋肉別で、部位別の推移と合計、種目ごとの推移
- **バックアップ**: 設定 → JSON（全データ）/ CSV（履歴）で保存し、そのファイルから復元

### データの保存について
- 記録はスマホのブラウザ内に保存され、外部には送信されません
- ブラウザのデータ削除や機種変更で消えるため、定期的に「設定 → JSONで保存」をしてください

### 公開の設定
GitHub の Settings → Pages で `main` ブランチ・`/ (root)` を公開しています。
